# Results & Evaluation Artifacts

This directory stores reproducible evaluation metrics, comparison summaries, and diagnostic reports produced by the TaskTune pipelines.

### Artifact Overview

1. **`baseline_comparison.json`**:
   - Generated by: `python src/compare_baselines.py`
   - Compares the majority-class heuristic against TF-IDF + Logistic Regression on a fixed stratified test split (default: 25% test, random state 42).
   - Contains accuracy, macro-F1, per-class precision/recall/F1, confusion matrices, and reproducibility metadata (dataset SHA-256, package versions, and split indices).

2. **`cross_validation.json`**:
   - Generated by: `python src/evaluate_cross_validation.py`
   - Evaluates the TF-IDF + Logistic Regression pipeline across 5 stratified folds.
   - Vectorization is fitted strictly within each fold's training split to prevent leakage. Reports fold-level metrics plus across-fold means and population standard deviations.

3. **`error_analysis.json`**:
   - Generated by: `python src/analyze_errors.py`
   - Performs granular diagnosis of classifier mistakes on the held-out test split.
   - Reports overall accuracy/error rate, per-class error counts, a complete record of test predictions, and detailed inspection of misclassified texts.

4. **`model_comparison.json`**:
   - Generated by: `python src/compare_models.py`
   - Fairly compares two suitable classical text classifiers (Logistic Regression vs. Multinomial Naive Bayes) using identical training/testing splits, identical feature vectorization, and identical evaluation metrics.

5. **`dataset_profile.json`**:
   - Generated by: `python src/profile_dataset.py`
   - Summarizes dataset health, total and valid record counts, class distributions, duplicate detections, invalid records, and character/word length statistics.

### Limitations Note

The sample dataset contains 75 hand-crafted illustrative messages (25 per class). These evaluation artifacts demonstrate pipeline functionality and methodology; they are not an estimate of real-world or production generalization.
